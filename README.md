# burirodev-scripts

Reusable PHP helper utilities I use across my Laravel and vanilla PHP projects.

> I got tired of writing the same `dd()` and `date_format()` logic in every new project. So I packaged it. Nothing fancy. Just functional.

---

## Installation

Clone this repo or copy the `src/` folder into your project's `app/Helpers` directory.

```bash
git clone https://github.com/BuriroDev/burirodev-scripts.git
